2026-09-28, macOS. 사용자가 지정한 `gpt-6-astra`/Codex, `claude-opus-5.5`/Claude Code, `grok-4.7`/Grok을 각각 `xhigh`로 실행했다. Claude CLI는 점 표기 모델명을 거절해 실제 지원 ID인 `claude-opus-5-5`를 사용했다. Grok은 `grok-4.7`을 선택 가능한 모델로 표시하지만 실행 usage에는 `grok-4.7-build`로 기록한다. Codex JSONL은 실제 서버 모델 ID를 제공하지 않아 요청 ID만 확인됐다. 추론 강도는 각 CLI에 `xhigh`를 명시했으며 서버 측 적용값은 별도로 노출되지 않았다.

이 비교는 **후보 워크플로의 4사례 파일럿**이다. B01(명확한 CLI 옵션), B03(공유 함수의 null 버그), B04(계획만 검토), B05(비웹 라이브러리 sprint·로컬 모의 PR)를 세 모델에 각각 한 번씩 수행했다. 모든 모델이 사례별로 같은 첫 요청 바이트(`SHA-256 4ec46ada1f6d919ad32bcd227b65fbe99391166b9f53ede34279460f4fc3384e`), 같은 정규화된 후보 스킬 본문과 같은 Git seed tree를 받았다. seed tree는 순서대로 `699cae45`, `4baaa275`, `a077c714`, `cf440dd9`로 세 모델 사이에 일치한다. 별도 일회용 Git 저장소를 사용했고 하위 에이전트는 비활성화했다. Claude는 Agent 도구 없이 실행했고 결과의 `subagent_stats.spawned`가 모든 유효 사례에서 0이었다.
